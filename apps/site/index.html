Where the project stands

Credspan is under development. The current delivery is a local synthetic membership sandbox with a modified walt.id wallet peer.

General wallet compatibility, ecosystem conformance and production deployment remain future work. The repository is currently private.

This public site introduces the project. It does not collect credentials or connect to the local API.
